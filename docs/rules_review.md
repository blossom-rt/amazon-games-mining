# 关联规则人工复核

## 背景

`also_buy` 是商品页的推荐位，不是收银小票。P3 用 19,032 个购物篮得到 1,855 条原始规则，经 `lift>1` 与对称去重后剩 932 条。本复核补充两类信息：

- `conviction`：前件出现时后件不出现的反事实强度，数值越高越接近“前件几乎必然推出后件”；
- `same_series`：标题去掉平台、版本、末尾编号后，取前三个实词，判断前后件是否同系列。

## 复核结果

- 932 条规则中 34 条为同系列，`conviction` 中位数 3.21；
- top 8 规则全是 hidden-object 下载版互推，lift 122–134、conviction 6.9–31.8；
- 三条支持度/置信度阈值：0.02/0.15 → 0 条；0.01/0.20 → 21 条；0.005/0.10 → 932 条；
- 规则只覆盖 755 个频繁商品，长尾商品没有规则。

## 判断

1. 高 conviction 不等于真实购买。它只说明在 `also_buy` 推荐位中前后件高度绑定，仍受平台推荐策略影响。
2. 同系列规则适合做“系列页/捆绑页”的组合推荐，不适合解释为跨品类购买。
3. top 规则中的 hidden-object 下载版多为同一发行商批量填写推荐位；`Euro Trip II → House Season` 这类规则 lift 134，但 support 只有 0.58%，不能代表大盘。
4. 支持度阈值提高到 0.02 时规则为 0，说明强规则只存在于小众团；主流商品对需要更低支持度，代价是规则数量暴涨。

## 建议

- 业务解读按“同系列互补”“同平台粉丝重合”“下载版封闭团”三类写，不写“买了 A 就会买 B”；
- 若用于推荐，先按 `same_series` 分组，再在组内排序，避免跨品类误推；
- 真实购买篮需要订单数据；在没有订单数据前，`also_buy` 结论只作为推荐位分析。
